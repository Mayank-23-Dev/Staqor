# Challenge Specification Template (Person 4 Content Workspace)

## Metadata
- **Slug:** `responsive-pricing-table`
- **Title:** `Interactive Pricing Table with Monthly/Annual Toggle`
- **Track:** `html-css`
- **Difficulty:** `easy`
- **Estimated Time:** `25 mins`

## Problem Description
Create a responsive 3-tier pricing table (Free, Pro, Enterprise) with an interactive monthly/annual billing cycle toggle that dynamically updates the displayed price.

## Requirements
1. **Semantic HTML Structure:** Use accessible markup with proper headings, lists, and button elements.
2. **Responsive Flexbox/Grid Layout:** Cards must stack vertically on mobile (<768px) and display as 3 columns on desktop.
3. **Interactive Toggle:** Clicking the toggle switch must update the pricing amounts between Monthly and Annual with a 20% discount applied.
4. **Visual Hierarchy:** The middle "Pro" tier card must be visually highlighted with a badge and primary accent border.

## Rubric Definition
- **Criteria 1 (35%):** Design fidelity, spacing, contrast, and responsive layout across desktop and mobile.
- **Criteria 2 (35%):** Correct DOM event handling on billing toggle and price calculation logic.
- **Criteria 3 (30%):** Semantic markup cleanliness, accessibility attributes, and CSS structure.
